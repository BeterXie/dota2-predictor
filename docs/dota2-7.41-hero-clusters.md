# Dota 2 7.41 职业比赛英雄集群与阵容搭配

## 1. 文档范围

本文整理自完美世界电竞社区转载的 Noxville 7.41 版本英雄集群分析：

- 来源：[来自数据分析师 Noxville 的 7.41 版本英雄集群分析](https://news.wmpvp.com/news.html?id=296715&gameTypeStr=1)
- 数据范围：7.41 版本职业比赛
- 搭配矩阵样本：770 场比赛
- 整理日期：2026-07-21

这不是传统的“控制、爆发、推进、后期”等人工英雄分类。集群对象是：

> 英雄 + 队内角色（Core/Support）+ 分路（safe/off/mid/roam）

因此，同一英雄可以因为角色或分路不同而进入多个集群。例如：

- 蝙蝠骑士作为劣势路核心属于 C5，作为劣势路辅助属于 C7；
- 钢背兽作为劣势路核心属于 C3，作为优势路核心属于 C4；
- 光之守卫作为劣势路辅助属于 C0，作为中路核心属于 C8。

## 2. 图表术语

| 原图术语 | 本文译法 | 含义 |
|---|---|---|
| `Core` | 核心 | 该英雄、角色与分路组合按核心英雄统计 |
| `Support` | 辅助 | 该英雄、角色与分路组合按辅助英雄统计 |
| `Unique` | 专属组合 | 该英雄只适用于一个“角色 + 分路”组合 |
| `Flex` | 摇摆组合 | 该英雄在多个“角色 + 分路”组合中出现 |
| `safe` | 优势路 | 原图中的 safe lane |
| `off` | 劣势路 | 原图中的 off lane |
| `mid` | 中路 | 原图中的 mid lane |
| `roam` | 游走 | 原图中的 roam |

英雄总览图中带红框的格子表示该“英雄 + 角色 + 分路”组合不足 20 场。本文将其标为“低样本”。低样本不是英雄弱，而是数据不足，不能据此得出稳定结论。

## 6. 同类英雄能否重复选择

### 辅助

- **可以重复：C7。** 双 C7 为 106 场、57.5%，是辅助矩阵中最强的结果。
- **不要重复：C0。** 双 C0 为 69 场、36.2%。
- **暂按不要重复：C2。** 双 C2 只有 15 场、46.7%，证据不足且没有正向信号。

### 核心

- **可以有限重复：C3。** 双 C3 为 83 场、51.8%，是唯一具有相对充分样本且高于五成的同类核心组合。
- **最好只有一个：C4。** 双 C4 为 43 场、48.8%，而 C4 与不同集群搭配通常更好。
- **避免重复：C9。** 双 C9 为 32 场、31.2%。
- **证据不足：C1、C5、C6、C8。** 对角样本分别只有 4、11、5、8 场，不能因为表面胜率高或低直接得出结论；实用上应优先选择不同集群。

## 7. 阵容分析用法

分析一套阵容时，建议按以下步骤使用，而不是把矩阵中的胜率直接当成整套阵容胜率：

1. 按实际承担的角色和分路，把两个辅助映射到 C0、C2 或 C7。
2. 按实际承担的角色和分路，把核心映射到 C1、C3、C4、C5、C6、C8 或 C9。
3. 查询辅助二人组的唯一一对搭配。
4. 对三个核心分别计算三组两两关系。
5. 优先排除样本相对充分且明显负向的核心对，例如 C3 + C6、C8 + C6、C9 + C6。
6. 不要把三组两两胜率相乘或简单平均成胜率；这些事件并不独立。
7. 当英雄、角色或分路不符合表中定义时，不要强行套用该集群。

## 8. 数据限制

- 结论只对应 7.41 版本职业比赛，版本变化后需要重新聚类和统计。
- 表中胜率是相关性，不代表某个集群组合直接导致胜负。
- 队伍实力、BP 顺序、对线克制、比赛地区和赛事级别等因素没有在转载文章中展开控制。
- 原图颜色表示 Wilson 置信区间下限，用于减少小样本造成的颜色误导；格子中的百分比仍是原始胜率。
- 英雄总览中的红框只表示该英雄在指定角色和分路下不足 20 场，不等于该英雄所属集群整体低样本。
- 原文只明确给 C3“偏发育”、C4“泛用型”两个语义描述；其他 C 编号是数据聚类标签，不应自行解释成固定战术名称。
