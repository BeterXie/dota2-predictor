# Use OpenDota as postmatch authority

For every Exact Map Link, OpenDota owns the canonical result and base match detail, while STRATZ may add explicitly attributed enrichment only. Provider fields are never silently substituted for one another, RayBet and Vision remain live-evidence sources, and postmatch data cannot change an Immutable Decision; this preserves auditable identity and causal boundaries even when one provider is delayed or incomplete.
